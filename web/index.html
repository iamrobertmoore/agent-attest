Check the admission for yourself

Google's Agent Registry records that an agent exists. It does not record what code that agent is running. agent-attest gates admission on a Confidential Space attestation, and every verdict it reaches is one you can recompute here, in your own browser, against a Google root certificate pinned into this page at build time.

Nothing on this page trusts our servers. The signature check, the certificate chain walk and the root comparison all run locally in WebCrypto. The only network call is a public, read-only fetch of the admission record, and if you think we faked that, the cryptography above it still holds independently.

What a green result does and does not mean. It means this token was signed by Google's Confidential Space attestation service, that the certificate chain builds to the root pinned in this page, and that the image digest matches the one the agent was admitted under. It does not mean the code is correct, safe, or does what it claims. Pinning an image pins the code, not the behaviour.
